# Elliott+

Render-ready Elliott+ site.

## Files

- `index.html` — website
- `server.js` — Node web server
- `package.json` — npm start command
- `render.yaml` — Render Blueprint configuration

## Render

The Blueprint uses:

- Build Command: `npm install`
- Start Command: `npm start`

You can connect the GitHub repository to Render and deploy it as a Blueprint.
